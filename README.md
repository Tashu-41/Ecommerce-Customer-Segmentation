# E-Commerce Customer Segmentation

## Project Overview

This project focuses on segmenting e-commerce customers based on their purchasing behaviour using Machine Learning clustering algorithms.

## Objectives

* Perform RFM (Recency, Frequency, Monetary) analysis.
* Apply K-Means clustering.
* Apply DBSCAN clustering.
* Reduce dimensions using PCA.
* Visualize customer segments using t-SNE.
* Generate actionable marketing personas.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset

UCI Online Retail Dataset.

https://archive.ics.uci.edu/dataset/352/online+retail

## Machine Learning Algorithms

1. K-Means Clustering
2. DBSCAN Clustering
3. Principal Component Analysis (PCA)
4. t-SNE

## Results

Customer groups are identified based on purchasing behaviour. These segments can help businesses develop targeted marketing strategies, improve customer retention, and increase revenue.

## Conclusion

This project demonstrates how unsupervised machine learning techniques can be used for customer segmentation and business decision-making.
